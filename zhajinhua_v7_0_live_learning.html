🃏 V7.0 实时动态牌角学习测试器

真正的实时视频分析 + 本机样本学习。先用真实牌角教会程序，再测试移动识别。本版是实验性模板匹配，不是已训练好的52张牌AI模型。

① 摄像头与画面

画面中央的黄色框是识别区域。点击画面中的牌角可移动识别框；拖动可调整位置。请让数字和小花色同时位于框内，尽量占满框。移动牌时框会尝试跟随相似图案。

② 教程序认识牌角

拿一张真实扑克牌，让数字和小花色出现在黄色框内，选中实际牌名，点击“学习当前牌角”。建议同一张牌分别采集正放、斜放、倒放等多个清晰样本。学习记录仅保存在当前浏览器中。

准备就绪

识别采用连续帧投票，结果不稳定时显示“待确认”。只与已经学习过的牌比较；如果只学习一张牌，无法可靠区分它与其他牌。请至少学习多张不同的牌再测试。

使用范围与限制

这个原型识别的是框内牌角图案，不会自动知道隐藏的牌。快速移动造成严重模糊、牌角太小、变形太大或不同印刷字体，可能导致错误。现在没有内置52张训练完成的视觉模型；要达到高准确率，需要真实标注数据训练并实测。手机摄像头请通过 GitHub Pages 的 HTTPS 地址打开。
